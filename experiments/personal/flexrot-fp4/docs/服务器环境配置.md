# 服务器环境配置

## 建议基线

- Linux x86_64
- 单 NVIDIA RTX 4090 24GB
- Python 3.10
- PyTorch 2.5 + CUDA 12.1（以服务器驱动兼容为准）
- Transformers 4.51–4.57

环境以 `environment.yml` 为首选，`requirements.txt` 用于已有 PyTorch/CUDA 环境。不要在同一环境中同时安装 conda torch 与另一套不兼容 pip torch。

## 显存策略

逐层 MR-GPTQ 的约束是：单模型 CPU 实例、current layer 上 GPU、current-layer Hessian、activation cache 在 CPU/磁盘、量化权重原位替换、每个 Linear/层结束立即释放临时张量。禁止同时保留 BF16 整模 GPU copy、旋转整模 copy、量化整模 copy、所有 Hessian 与所有 activation cache。

## 磁盘建议

至少预留 150GB：三个 7B/8B 模型权重约 45–55GB，三个逐 Linear calibration cache 约 30–36GB，加上 Hugging Face 临时缓存、module artifacts 与结果。实际占用取决于 snapshot 去重和文件系统。

## 网络与凭据

Qwen 模型公开；Llama 3.1 gated，需要在 Hugging Face 接受条款并登录。`HF_ENDPOINT` 可选，token 只保存在 Hugging Face CLI 凭据或环境变量，不写入仓库。
