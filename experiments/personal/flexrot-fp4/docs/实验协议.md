# 实验协议

## 论文对齐主协议

- dtype：BF16 原模型，FP32 scale/Hessian/reference math。
- calibration：FineWeb-Edu `sample-10BT`，长度 2048，按 seed 流式 shuffle 后在文档内随机取连续窗口。
- pilot：128 条序列，seed 42/43/44。
- paper：1024 条序列，seed 42/43/44/45/46。
- RTN/GPTQ/MR-GPTQ：共用相同的逐层输入捕获、activation absmax calibration 和量化后 block 输出传播。
- evaluation：WikiText-2 test PPL 固定前 8 个 2048-token 窗口作为辅助指标；论文比较另跑 MMLU-CoT、GSM8K、HellaSwag、WinoGrande。
- rotation：所有受支持 decoder Linear 使用统一 native block；NV H16，MX H32。
- GPTQ：damping=0.01，traversal chunk=128。
- MR-GPTQ：Static ActOrder=true，MSE-grid=true，sequential deployment calibration=true。
- MXFP4：使用 FP-Quant scale-fitting 有效尺度；历史 `ceil(log2(amax/6))` 只允许显式 `--mxfp-scale-mode legacy`。

## 运行顺序

1. baseline：仅运行 0° identity 与 45° 标准 Hadamard，pipeline 为 RTN/GPTQ/MR-GPTQ。
2. baseline 全部 complete 后，orchestrator 才允许进入 FlexRot 弱角度扫描。
3. 弱角度先用 PPL 筛选；进入论文主表的候选必须补四项任务和多 seed。

```bash
python scripts/run_paper_experiments.py --profile pilot --stage baseline
python scripts/run_paper_experiments.py --profile pilot --stage flexrot
python scripts/run_paper_experiments.py --profile paper --stage baseline
```

配置冻结在 `configs/experiments/paper_aligned.yaml`。

## 结果有效性门槛

结果 JSON 必须包含 model、format、pipeline、theta、calibration dataset/长度/数量/seed、MXFP scale mode、PPL/任务结果和软件版本。status 不为 complete、resume 配置不一致、发生 OOM 后改变协议但未记录，均不得进入主表。
