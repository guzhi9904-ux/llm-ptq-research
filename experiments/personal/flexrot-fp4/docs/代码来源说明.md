## 关键语义保持

- E2M1 幅值码字：`0, 0.5, 1, 1.5, 2, 3, 4, 6`。
- NVFP4：block16，`raw=amax/6`，`global=max(raw)/448`，local scale 编码为 E4M3。
- MXFP4：block32，`scale=2**ceil(log2(amax/6))`，指数限制 `[-127,127]`，零块 exponent=-1。
- GPTQ：`H=2 X.T X/n`，1% damping，128 列 traversal chunk；MR-GPTQ 启用 Static ActOrder 与 MSE-grid。
- Phase 7：8×512 evaluation windows，预测 token 为 4088；0° arm 实现为 no rotation。

## 与旧代码的有意差异

1. 新代码不再 import `quantization_harness`、`fp4_channel_reorder`、`mxfp4_learned_transform` 或 QuaRot，因此 clone 后可独立运行。
2. 路径全部由 `configs/paths.yaml` 提供，不保留旧 Windows 绝对路径。
3. 核心实现按职责拆分并增加中文 docstring；数学和 scale 规则保持已验证语义。
4. 逐层 runner 的断点文件同时保存 next-layer 输入和每个量化 Linear artifact，避免 resume 后丢失已完成层。
