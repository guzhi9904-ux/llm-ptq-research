# 模型支持说明

下列模型 ID 已按 Hugging Face 官方模型页核对。显存是 BF16 权重与常规 forward 的工程估计，不是硬保证；calibration cache 按 4096 行、七类 Linear 输入、BF16 粗估。

| 短名 | Hugging Face ID | 参数量 | BF16 权重/运行估计 | calibration cache | Gated | HF token |
|---|---|---:|---:|---:|---|---|
| `qwen25_7b` | [Qwen/Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) | 7.61B | 权重约 15.2GB；整模 PPL 通常约 17–20GB | 约 9–11GB | 否 | 否 |
| `qwen3_8b` | [Qwen/Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B) | 约 8B | 权重约 16GB；整模 PPL 约 18–22GB | 约 10–12GB | 否 | 否 |
| `qwen3_4b` | [Qwen/Qwen3-4B](https://huggingface.co/Qwen/Qwen3-4B) | 约 4B | 权重约 8GB；运行约 10–13GB | 约 6–8GB | 否 | 否 |
| `llama31_8b` | [meta-llama/Llama-3.1-8B-Instruct](https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct) | 8B | 权重约 16GB；整模 PPL 约 18–22GB | 约 10–12GB | 是 | 是 |

## 必跑目的

### Qwen2.5-7B-Instruct

同家族 scale-up，验证 Qwen2.5-1.5B 的 NV/MX strength 现象能否扩展到 7B。

### Qwen3-8B

验证 Qwen 新一代架构；若最终整模评测在 24GB 仍 OOM，允许按预注册规则换 Qwen3-4B，并在结果中明确标记。

### Llama-3.1-8B-Instruct

跨模型族验证。模型页要求共享联系信息/接受许可后访问，下载前执行 `huggingface-cli login`。

## 适配边界

当前 adapter 寻找 `model.layers` 下的 `q_proj/k_proj/v_proj/o_proj/gate_proj/up_proj/down_proj`。MoE、合并 QKV、非 Llama 风格 decoder 或 in_features 不能被 native block 整除的模型不在当前支持范围。
